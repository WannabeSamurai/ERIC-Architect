# ERIC

## Current Status

ERIC is an active private engineering project.

It is **not** released as downloadable software. It is **not** a finished customer product. It is **not** publicly demonstrated as a self-operating business system, a safe controller of customer files or devices, or a complete managed-service platform.

This repository does not make a claim unless that claim has been demonstrated. Design direction is stated separately.

## What Has Been Demonstrated

- A private local AI runtime can run language models on the operator's own hardware.
- The engineering environment can run structured model tests and retain model-output records.
- Parts of the codebase have automated tests.
- The Android project has built successfully.

These facts are a foundation. They are not proof that ERIC is ready to run a customer's business process.

## Development Direction — Not a Current Capability Claim

ERIC is being developed as a local-first system around language models rather than as one model or one chatbot. The intended system is meant to add controlled execution, durable records, evidence, recovery, diagnostics, and interfaces around local models.

The proposed future deployment model is private and customer-specific: a system installed inside a customer's approved environment and maintained as a technical service. That is product direction, not an available public offering.

## Public Versus Private

This repository contains safe public statements about the project and its direction.

It does not include production source code, credentials, customer data, operator records, private bridge state, machine-specific execution paths, deployment secrets, or private diagnostic logs.

## Evidence Rule

A test result proves only what that test actually showed. A successful build proves that the project built. A running service proves that it started. Neither proves a finished customer feature unless the complete feature has been demonstrated and accepted.
