# Contributing to the ERIC Public Architecture Surface

This repository exists so outside reviewers can inspect ERIC's public architecture and offer useful criticism without receiving access to the private production repository or host.

## Default Access Model

No private access is required to contribute.

You may read and clone this public repository, open an issue describing a defect, architectural concern, question, or proposed improvement, or fork this repository and submit a pull request affecting the public documentation.

You do **not** receive, by contributing here, access to the private ERIC source repository, ERIC's live runtime or host machine, development-bridge infrastructure, credentials, secrets, private evidence, operator data, or device access.

## Useful Contributions

High-value review is specific and falsifiable. Good contributions identify a concrete contradiction, missing boundary, unsafe assumption, unsupported capability claim, architectural failure mode, test gap, or a better mechanism and explain why.

A proposed implementation change may be described publicly, but acceptance into the private ERIC codebase is a separate operator-controlled process.

## Evidence Standard

Do not convert an aspiration into a capability claim. Distinguish proposal from implementation, implementation from test coverage, test coverage from live validation, and historical validation from current runtime state.

## Security

Do not post credentials, tokens, private keys, personal/operator data, machine-specific security details, or suspected sensitive information in a public issue or pull request. Follow [SECURITY.md](SECURITY.md).

## Authority

Pull requests are proposals. Submission does not grant write access or authority over the private ERIC system.
